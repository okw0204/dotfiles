description: ファイルを LLM Wiki に取り込む
---
スラッシュコマンドの引数を LLM Wiki に取り込む。

今回の引数: $ARGUMENTS

最初に必ず次の AgentSkill を読み込み、その指示に従うこと:

- `skill://managing-llm-wiki`
- `skill://japanese-documentation`
- `skill://obsidian-cli`
- `skill://obsidian-markdown`

追加の振る舞い:

- 引数に URL / リンクまたはファイル・ディレクトリのパスがある場合は、明示された資料だけを対象にし、`managing-llm-wiki` の「書き込みの許可」と「再取り込みと処理結果」に従う。複数指定はまとめて扱い、`raw/` の未処理候補探索には進まない。
- 引数なしの場合だけ、`LLM Wiki/raw/` を確認し、「再取り込みと処理結果」に従って候補を特定する。処理済みの資料は除外し、再試行候補と状態不明の資料を区別して提示する。候補探索ではファイルを変更せず、ユーザーが確認した資料をまとめて取り込む。
- 引数があるのに対象の URL / パスを特定できない場合は、その対象を確認する。引数なしとは扱わない。
- 取り込みによる変更がある場合は、`managing-llm-wiki` の「Git 同期の安全条件」に従って commit / push する。安全条件を満たさない場合は同期を見送り、理由を報告する。
